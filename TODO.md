## 4. Directive Alpha: Export Sanitization Layer

Implement a filtering matrix that intercepts the cookie array generated by `chrome.cookies.getAll()` before serialization.

* **Cloudflare/Bot Token Purge:** Drop ephemeral transit tokens (`__cf_bm`, `_cfuvid`, `__cflb`, `_dd_s`, `_abck`).
* **Timestamp Ticket Purge:** Drop sliding-window auth tickets (`__Secure-1PSIDTS`, `__Secure-3PSIDTS`).
* **Telemetry Purge:** Drop analytics signatures (`_ga*`, `_gid`, `_gcl_`, `sensorsdata*`, `sajssdk*`, `_v-*`).
* **Validation:** Ensure the resulting array retains core authentication tokens and passes intact to the formatting modules.

## 5. Directive Beta: Cryptographic Integration (Web Crypto API)

The export pipeline must be updated to utilize the browser's native Web Crypto API to ensure zero-dependency security.

* **Key Derivation:** Implement PBKDF2 (Password-Based Key Derivation Function 2) to derive a 256-bit cryptographic key from a user-provided password.
* **Cipher Mechanism:** Encrypt the sanitized payload using AES-256-GCM (Galois/Counter Mode) to ensure both confidentiality and authenticated data integrity.
* **Payload Structure:** Wrap the final export into a consolidated JSON object containing the Initialization Vector (IV), the cryptographic salt, and the ciphertext.
* **Import Decryption:** The restoration engine must intercept encrypted files, prompt for the password, extract the IV and salt, and execute in-memory decryption before passing the payload to the formatting functions.

## 6. Directive Gamma: Restoration Engine Hardening

Overhaul the import execution loop to safely parse payloads and ensure robust, async execution.

* **URL Synthesis Protocol:** The restoration logic must dynamically synthesize the required `url` property for `chrome.cookies.set()`. Strip leading dots from the `domain`, append the `path`, and prefix with `https://` (if `secure` is true) or `http://` (if false).
* **Asynchronous Batching:** Wrap the restoration loop in a `Promise.allSettled()` block. A single rejected cookie write must not terminate the sequence.
* **Idempotent Upsert:** The restoration action must act purely as an upsert sequence. Do not execute a global `chrome.cookies.remove()` sweep prior to setting cookies, preserving independent live sessions.

## 7. Directive Delta: CRUD Integrity & Parsing Accuracy

* Systematically verify that inline editing and deletion features within `CookieManager.tsx` and `cookieManager/index.ts` reflect instantaneous state changes without data corruption.
* Audit the Netscape parsing regex to handle edge cases (e.g., `#HttpOnly_` prefixes) and accurately map tab-delimited values to the correct boolean properties without data loss.
